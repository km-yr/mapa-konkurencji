# Mapa konkurencji – Kongsberg Maritime Poland (Szczecin)

Statyczna kopia mapy konkurencji na rynku pracy w Szczecinie i okolicach, stan na 12.11.2026.
Wersja tylko do odczytu: nie ma tu edycji, propozycji zmian ani przycisku „Aktualizuj”.

## Pliki

- `index.html` – strona (tablica sektorów, inwestycje, filtry, szczegóły ze źródłami)
- `data.js` – dane: 32 firmy, 9 inwestycji

## Publikacja na GitHub Pages

1. Wrzuć oba pliki do repozytorium (np. do katalogu głównego).
2. Settings → Pages → Source: „Deploy from a branch”, wybierz gałąź `main` i folder `/ (root)`.
3. Strona będzie pod adresem `https://<użytkownik>.github.io/<repozytorium>/`.

Stronę można też otworzyć lokalnie, klikając dwukrotnie `index.html`.
